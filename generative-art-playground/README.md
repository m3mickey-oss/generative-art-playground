# Generative Art Playground

フローフィールド（ノイズベースのベクトル場）上を漂うパーティクルで、模様を描くジェネレーティブアートのデモです。ビルド不要の単一HTMLファイルで、ブラウザで開くだけで動作します。

## 使い方

`index.html` をブラウザで直接開いてください(ローカルサーバーは不要です)。

```bash
start index.html   # Windows
```

## 操作方法

- 画面右上のスライダーで、パーティクル数・速度・ノイズの粗さ・渦の強さなどをリアルタイムに調整できます。
- キャンバス上をクリック／タップすると、その場所に渦(うず)が発生します。
- **ランダム化**: 全パラメータをランダムな値に設定します。
- **画面クリア**: 描画済みのトレイルを消去します。
- **一時停止 / 再開**: アニメーションを止める・再開します。
- **PNG保存**: 現在の描画結果をPNG画像としてダウンロードします。
- 右上の ⚙ ボタンでパラメータパネルの表示・非表示を切り替えられます。

## 技術メモ

- 外部ライブラリなし(Vanilla JS + Canvas 2D API)。
- パーリンノイズ風の value noise を自前実装し、時間軸を加えた2Dフローフィールドを生成しています。
